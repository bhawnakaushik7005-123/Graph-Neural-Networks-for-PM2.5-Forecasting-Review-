## 2. About This Repository

This repository provides the supplementary materials and supporting evidence for the systematic review titled *“Graph Neural Networks for PM₂.₅ Forecasting: Review on Recent Advancements, Challenges, and Outlooks.”*

The review systematically examines the development and application of graph neural network (GNN) approaches for forecasting fine particulate matter (PM₂.₅) concentrations.

The reviewed studies are analyzed according to their graph-learning architectures, graph-construction strategies, spatial and temporal modelling mechanisms, environmental inputs, forecasting performance, experimental designs, and reproducibility characteristics.

The review covers graph convolutional networks, graph attention networks, spatiotemporal GNNs, adaptive and dynamic graphs, multi-graph approaches, graph–Transformer architectures, hypergraph methods, and emerging continuous-time graph-learning approaches.

The primary purpose of this repository is to improve the **transparency, traceability, and reproducibility** of the literature selection, data extraction, methodological classification, and evidence synthesis.
